# Folio · Editor de PDF

Editor de PDF gratuito que funciona en el navegador. Los archivos se procesan en el dispositivo del usuario y no se suben a ningún servidor.

## Herramientas

- **Editar**: agregar texto, firma dibujada, imágenes, recuadros para tapar y resaltado.
- **Unir**: combinar varios PDF en uno.
- **Organizar**: reordenar, rotar, eliminar y extraer páginas.
- **Dividir**: por página, por rangos o cada N páginas (descarga en .zip).
- **Comprimir**: tres niveles de compresión.
- **Imágenes a PDF**: JPG, PNG o WEBP a PDF (Carta, A4 o tamaño de la imagen).
- **Marca de agua y números de página**, con vista previa.

## Uso

Abrí `index.html` en el navegador, o publicalo con GitHub Pages
(Settings → Pages → Branch: `main` / carpeta raíz).

## Librerías

- [pdf-lib](https://pdf-lib.js.org/) 1.17.1
- [PDF.js](https://mozilla.github.io/pdf.js/) 3.11.174
- [JSZip](https://stuk.github.io/jszip/) 3.10.1

Se cargan desde cdnjs, así que la página necesita conexión a internet la primera vez que se abre.
